# OKK 微信全能体验增强模块

基于 LSPosed / Xposed 的微信全能体验增强模块，独立插件，不修改微信本体。

## 功能

保留上游全部 37 项功能，其中 6 项核心功能默认开启：

- 消息防撤回（文本/图片/语音/视频）
- 朋友圈防删除
- 朋友圈评论防撤回
- 屏蔽热更新
- 存储重定向
- 自行撤回保留

其余功能包括：聊天增强、会话分组、界面美化、输入状态屏蔽、修改消息、视频号下载、虚拟定位、密友、圆形头像、主题壁纸、气泡皮肤等。

## 适配

- 微信 8.0.79（主适配区间 8.0.69–8.0.79）

## 安装

1. 手机 Root + LSPosed
2. 安装本仓库 Release 的 APK
3. LSPosed 模块页勾选本模块，作用域勾选微信 `com.tencent.mm`
4. 强停微信后重开
