# Lokk 微信全能体验增强模块

基于 LSPosed / Xposed 的微信全能体验增强模块（开源二改版），独立插件，不修改微信本体。

## ⚠️ 升级前必读

- **模块已正式更名为 Lokk**（原 OKK）。
- **必须先卸载旧版本模块，再安装本版本**，不要直接覆盖安装。旧版配置目录与新版不兼容，直接覆盖可能导致设置页无法打开或功能异常。
- 卸载旧版后重新安装 APK，并在 LSPosed 中重新勾选模块与作用域。

## 适配范围

**仅适配微信 8.0.79 国内版与 Play 版。** 其他微信版本未经验证，不保证可用。

## 功能

保留上游全部 37 项功能，其中核心功能包括：

- 消息防撤回（文本/图片/语音/视频）
- 朋友圈防删除、朋友圈评论防撤回
- 屏蔽热更新
- 存储重定向
- 自行撤回保留
- 聊天增强、会话分组、界面美化、输入状态屏蔽、修改消息、视频号下载、虚拟定位、密友、圆形头像、主题壁纸、气泡皮肤等

> v1.2.63 起：**模块内所有功能默认关闭**，请进入模块按需开启。

## 安装

1. **先卸载旧版模块**
2. 手机 Root + LSPosed，安装本仓库 Release 的 APK
3. LSPosed 模块页勾选 Lokk，作用域勾选微信 `com.tencent.mm`
4. 强停微信后重开，进入模块按需开启功能
